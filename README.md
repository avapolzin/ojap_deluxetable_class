## Open Journal of Astrophysics LaTeX document class file with full AAS Journals deluxetable implementation.

Since OJAp does not support table rotation/some other deluxetable functionality [by default](http://www.thphys.nuim.ie/staff/pcoles/openjournal.cls), I've merged those commands from [AASTeX](https://journals.aas.org/aastex-v6-3-author-guide/) into the OJAp template document class file. 

I've also made an **UNOFFICIAL** [Overleaf template]() available that includes this option. To have the added table functionality available, simply set your document class to "openjournal_deluxetable".
